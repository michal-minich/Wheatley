# Jarvis Refresh Checklist

Use this every few months when refreshing the context package.

## 1. Source Discovery

- Search recent Obsidian notes for `Me`, `Systems`, monthly/daily organization files, family, health, finance, learning, Maker Garden, Wheatley, Know Lever, and agent workflow terms.
- Search the current workspace's topic and agent-state folders first.
- Search legacy roots only for migration input or older context.
- Search recent legacy project docs only when checking for direction changes
  not yet migrated into the current workspace.

## 2. Read Status

Update `Read Log.md` with:

- exact files read,
- sections read if partial,
- why the file mattered,
- what was not copied because it was sensitive or too raw.

## 3. Readable Docs To Revisit

- `Agent Profile.md`
- `About The User.md`
- `Life Areas.md`
- `Jarvis Assistant.md`
- `Project Index.md`
- project briefs
- `References/Personal Operating System.md`
- `References/Interests And Learning.md`
- `References/Long Term Vision.md`

## 4. Questions To Ask Of The Material

- What is the maintainer doing now that was not represented before?
- Which life areas are gaining or losing importance?
- What recurring friction should become a workflow, checklist, or script?
- What should agents stop assuming?
- What new project or AdHoc task should be promoted into a durable brief?
- What sensitive details should remain only in source notes?

## 5. Validation Prompts

After refreshing, test at least:

- one coding task,
- one personal admin task,
- one family/learning task,
- one health or finance research task,
- one long-term planning task,
- one communication/message drafting task.
