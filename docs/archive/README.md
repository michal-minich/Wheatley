# Documentation Archive

These files are useful but inactive engineering reference. Some are superseded;
others are detailed snapshots of the implementation at the time they were
written. None of them override the current contracts or active design documents.

- `architecture/` — architecture, deployment, storage, client, STT, and voice
  lifecycle snapshots
- `features/` — completed, deferred, or superseded feature designs
- `plans/` — completed implementation and verification plans
- `experiments/` — benchmark methods and results
- `evidence/` — synthetic screenshots and other visual evidence

Use the active [documentation entry](../README.md) for current contracts and
designs. When archive material disagrees with active documentation or code, the
active source wins.
