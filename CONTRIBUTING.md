# Contributing

Wheatley is early-stage personal software, but focused issues and pull
requests are welcome.

Before opening a change:

1. Do not include profiles, transcripts, credentials, local configuration,
   downloaded models, or generated runtime data.
2. Keep the server authoritative for persistent state and API behavior.
3. Prefer explicit paths and configuration over machine-specific assumptions.
4. Follow the [Coding Guide](docs/guides/Coding%20Guide.md) and run the relevant
   server, client, and integration checks for the changed contract.
5. Document new runtime dependencies and security-sensitive capabilities.

Bug reports are most useful when they include the operating system,
architecture, D and Node versions, Pi version, model provider, reproduction
steps, and sanitized logs.

By contributing, you agree that your contribution may be distributed under
the repository's MIT License.
